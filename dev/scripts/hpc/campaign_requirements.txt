# The campaign environment (dev/plans/slurm-benchmark-support.md, "The
# driver"): what the conda environment at CAMPAIGN_ENV takes from PyPI,
# pinned. `bash dev/scripts/hpc/campaign_env.sh build` creates the
# environment from conda-forge with the Python pinned below, zstd, gh and
# git, and installs this file with pip; campaign_submit.sh and
# campaign_finish.sh refuse an environment that differs from it
# (campaign_contract.py check-env). PyVBMC and gpyreg come from the
# campaign's source trees and are not pinned here: the check exempts a
# package installed from a path or editable, and one that conda installed.
#
# The file is frozen (Phase 1b of the plan, 2026-09-28): it pins every
# package of the first environment built from the direct requirements,
# dependencies included (`python -m pip list --format=freeze
# --exclude-editable` of that environment), and the Python below to its
# patch release, so that every environment built from the file, in any
# account, holds the same libraries. The direct requirements were PyVBMC's
# dependencies (the same at the release and at f91fdf0, the before arm's
# commit), gpyreg's (the same at v1.2.1 and v1.3.3), the test extra for the
# harnesses' test modules, psutil for the benchmark scripts, packaging for
# the environment check and CPU Torch for the stacking. pip, setuptools and
# wheel, which conda installs with the interpreter, are left to conda;
# conda also installs packaging, which stays pinned as a direct
# requirement.
#
